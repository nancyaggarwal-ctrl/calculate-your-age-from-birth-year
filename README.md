A simple yet creative C++ program that uses recursion to print a series of years along with the user's name — starting from their birth year up to the year 2025.

🌟 Features:

✅ Takes your name and birth year as input

✅ Prints your name with a sequence of years using recursion

✅ Demonstrates how recursion works in a fun, easy-to-understand way

✅ Counts how many recursive calls were made (and displays the total)

🧠 Concepts Used:

Recursion

Function calls and return values

Conditional statements (if, else)

User input (cin and cout)

⚙️ How It Works:

You enter your name and birth year.

The recursive function printN() prints your name with each calculated year.

The process continues until the condition k < 2025 becomes false.

The total count of recursive calls is displayed at the end.

This program helps understand:

How recursion works

How return values can count recursive calls

How to control recursive flow using base conditions
